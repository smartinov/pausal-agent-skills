Pausal Agent Skills

Skill-ovi za Claude Code i Codex koji vode back office paušalne agencije u Srbiji: fakture, KPO knjigu, limite prometa, obaveze, klijente i naplatu. Agent radi u tvom lokalnom folderu; podaci ne napuštaju tvoj računar osim ako to sam ne uradiš.

Status: u izradi, još nije spremno za upotrebu.

Skill-ovi

SkillŠta radi
/pausal:initPravi radni prostor agencije kroz kratak upitnik.
/pausal:fakturaB2B faktura (RSD ili EUR), kurs NBS, KPO red, nezavisan pregled.
/pausal:kpoKumulativ, limiti paušala i PDV-a, projekcija, udeo po klijentu.
/pausal:klijentPodaci klijenta, test samostalnosti, klauzule ugovora.
/pausal:naplataIzvod banke, uparivanje sa fakturama, devizni priliv.
/pausal:obavezeRokovi, podsetnici, kalendar, prenos na lični račun.

Propisi sa izvorima

Sve poreske činjenice žive u jednom fajlu, gde svaki red ima izvor, period primene i datum provere. Kad red nije proveren ili je istekao, skill kaže NEPROVERENO umesto da nagađa.

Instalacija

Claude Code:

claude plugin marketplace add smartinov/pausal-agent-skills
claude plugin install pausal@pausal-agent-skills

Codex:

codex plugin marketplace add smartinov/pausal-agent-skills
codex plugin add pausal@pausal-agent-skills

Preduslovi: Node.js (LTS) i Google Chrome. Zatim u praznom folderu pokreni /pausal:init.
